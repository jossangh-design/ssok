쏙만의 장점

한글 문서 (hwp·hwpx)

사진이 잔뜩 들어간 한글 파일도 지정한 용량에 알아서 맞춰 줄입니다. 문서 속 그림만 다시 압축하니 글자·표·서식은 그대로입니다.

PDF

먼저 문서 속 그림만 줄입니다. 그래도 크면 쪽을 그림으로 바꿔 맞춥니다. 이때는 글자 검색·복사가 안 될 수 있습니다.

사진

JPG·PNG는 화질과 크기를 조금씩 낮춰 목표에 맞춥니다. 아이폰 사진(HEIC)·WebP·BMP는 JPG로 바꿔 저장합니다.

학교 문서도
안심하고 넣으세요

쏙은 내 PC 안에서만 일합니다.

  • 인터넷으로 보내지 않습니다파일과 내용은 이 컴퓨터 밖으로 나가지 않습니다.
  • 원본은 그대로 둡니다줄인 파일은 '원래이름_쏙'으로 따로 저장합니다.
  • 사진 위치정보를 지웁니다촬영 장소(GPS) 정보를 빼고 저장할 수 있습니다.
  • 무료, 공개된 소스누구나 소스를 볼 수 있는 오픈소스(MIT)입니다.

처음 실행할 때 파란 창이 뜨면

쏙은 새로 나온 프로그램이라 윈도우가 아직 잘 모릅니다. 그래서 처음 한 번 "Windows의 PC 보호" 창이 뜰 수 있습니다. 아래처럼 두 번만 누르면 됩니다.

자주 묻는 질문

학교 컴퓨터에서도 설치되나요?+

관리자 권한 없이 설치됩니다. 학교마다 프로그램 설치를 막아 둔 곳이 있는데, 그럴 때는 바로 아래 '설치 없이 쓰는 버전'을 써 보세요.

설치하지 않고 쓸 수도 있나요?+

네. 설치가 막혀 있는 PC나 USB에 넣어 다니며 쓸 때는 '설치 없이 쓰는 버전'을 받으세요. 압축을 풀고 Ssok.exe를 실행하면 됩니다. 다만 새 버전이 나와도 저절로 바뀌지 않으니, 보통은 위의 무료 다운로드(설치판)를 추천합니다.

목표 용량까지 못 줄이면 어떻게 되나요?+

글자를 알아볼 수 없을 만큼은 줄이지 않습니다. 가장 많이 줄여도 모자라면 그 결과를 '목표 미달'로 알려 드립니다.

개인정보·코드 서명 정책

개인정보 · 쏙은 고른 파일을 이 컴퓨터 안에서만 처리합니다. 파일·파일 이름·내용을 인터넷으로 보내지 않고, 개인정보를 모으지 않습니다. 인터넷은 새 버전 확인(하루 한 번, 설정에서 끌 수 있음)과 사용자가 누른 업데이트 내려받기에만 씁니다.

코드 서명 · 배포 파일은 공개된 소스로 자동 빌드한 것만 올립니다. 업데이트 파일은 전자 서명과 지문(SHA-256)이 맞을 때만 설치합니다.

Code signing policy — Release files are built automatically from the project source only. This program will not transfer any information to other networked systems unless specifically requested by the user, except for an optional daily update check.
